## Feature 1: Workflow Versioning

### Description
Every save creates a new version. Users can compare versions and rollback.

### Database Changes
```sql
-- New table: workflow_versions
CREATE TABLE workflow_versions (
    id SERIAL PRIMARY KEY,
    workflow_id INTEGER REFERENCES workflows(id),
    version INTEGER NOT NULL,
    definition JSON NOT NULL,
    change_summary TEXT,
    created_by INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(workflow_id, version)
);
```

### API Endpoints
```
GET    /api/workflows/{id}/versions          # List versions
POST   /api/workflows/{id}/versions          # Create version
GET    /api/workflows/{id}/versions/{v}      # Get version
POST   /api/workflows/{id}/versions/{v}/rollback  # Rollback
```

### Backend Files
- `backend/app/models/workflow.py` — Add WorkflowVersion model
- `backend/app/api/versions.py` — Version CRUD endpoints
- `backend/app/services/version_service.py` — Business logic

### Frontend Files
- `frontend/src/components/VersionHistory.tsx` — Version list
- `frontend/src/components/VersionDiff.tsx` — Compare versions

### Acceptance Criteria
- [ ] Auto-create version on save (every 5 minutes or manual)
- [ ] List all versions with timestamps
- [ ] Compare two versions side-by-side
- [ ] Rollback to any version
- [ ] Version number increments automatically

### API Endpoints

```

### Backend Files
- `backend/app/core/compiler.py` — Python code generator
- `backend/app/api/workflows.py` — Compile/export endpoints

}

# Execution engine
def execute_workflow(trigger_data=None):
    context = {"trigger_data": trigger_data or {}}
    
    # Execute nodes in order
    result = execute_node("trigger", nodes["trigger"], context)
    context["trigger"] = result
    
    result = execute_node("http_1", nodes["http_1"], context)
    context["http_1"] = result
    
    result = execute_node("transform_1", nodes["transform_1"], context)
    context["transform_1"] = result
    
    return context

def execute_node(node_id, node_config, context):
    node_type = node_config["type"]

    if node_type == "trigger":
        return {"trigger_data": context.get("trigger_data", {})}
    elif node_type == "http_request":
        # Execute HTTP request
        pass
    elif node_type == "transform":
        # Execute transformation
        pass
    # ... other node types

if __name__ == "__main__":
    result = execute_workflow({"key": "value"})
    print(json.dumps(result, indent=2))
```

## Feature 4: Scheduling (Cron)

### Description
Schedule workflows to run automatically.

### Database Changes
```sql
-- Add to workflows table
ALTER TABLE workflows ADD COLUMN schedule VARCHAR(100);
ALTER TABLE workflows ADD COLUMN next_run_at TIMESTAMP;
ALTER TABLE workflows ADD COLUMN last_run_at TIMESTAMP;

-- New table: scheduled_runs
CREATE TABLE scheduled_runs (
    id SERIAL PRIMARY KEY,
    workflow_id INTEGER REFERENCES workflows(id),
    scheduled_at TIMESTAMP NOT NULL,
    status VARCHAR(50) DEFAULT 'pending',
    execution_id INTEGER REFERENCES executions(id),
    created_at TIMESTAMP DEFAULT NOW()
);
```

### API Endpoints
```
POST   /api/workflows/{id}/schedule     # Set schedule
DELETE /api/workflows/{id}/schedule     # Remove schedule
GET    /api/workflows/{id}/schedule     # Get schedule info
GET    /api/schedules                   # List all scheduled workflows
```

### Backend Files
- `backend/app/services/scheduler_service.py` — Cron parser + scheduler
- `backend/app/worker.py` — Check for due schedules

### Acceptance Criteria
- [ ] Set cron expression (e.g., "0 9 * * 1")
- [ ] Validate cron expression
- [ ] Run at scheduled times
- [ ] Show next run time
- [ ] Enable/disable schedule

## Feature 7: Credentials Management

### Description
Secure storage for API keys and tokens.

### Database Changes
```sql
-- New table: credentials
CREATE TABLE credentials (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    credential_type VARCHAR(50) NOT NULL,
    encrypted_value TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT NOW(),

### API Endpoints
```
POST   /api/credentials              # Create credential

### Backend Files

### Acceptance Criteria
